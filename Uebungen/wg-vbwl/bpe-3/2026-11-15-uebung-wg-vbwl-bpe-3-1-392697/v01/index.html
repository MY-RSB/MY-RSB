WG VBWL | BPE 3 | 1

Dieses Planspiel begleitet die Aufgaben 1.2, 1.4, 2.2 und 2.3. Sie beraten vier Fälle aus dem Haushalt Lindner und dem Alltag. Jede Stufe besteht aus einer Frage mit vier Antworten. Nach jeder Prüfung erhalten Sie eine fachliche Rückmeldung. Die Stufen laufen nacheinander. Ist eine Stufe richtig beantwortet, wird die nächste freigeschaltet.

Bearbeiten Sie das Planspiel allein an Ihrem Gerät. Es werden keine Daten gespeichert.

Stufe 1 von 4: Aufgabe 1.2

Diese Stufe wird freigeschaltet, sobald Sie die Stufe davor abgeschlossen haben.

Herr Dinkel liegt nach einer Zahn-OP noch benommen im Aufwachraum. Eine Pflegekraft legt ihm einen Handyvertrag vor, und er unterschreibt ihn.

Welche Rechtsfolge hat die Unterschrift?

Stufe 2 von 4: Aufgabe 1.4

Diese Stufe wird freigeschaltet, sobald Sie die Stufe davor abgeschlossen haben.

Familie Lindner und der Nachbar Rolf Gerner einigen sich per Handschlag darauf, dass Familie Lindner ein 800 Quadratmeter großes Gartengrundstück für 60.000 EUR erwirbt. Ein Notar wird nicht eingeschaltet, und der Vertrag wird nie beurkundet.

Welche Rechtsfolge hat die mündliche Einigung?

Stufe 3 von 4: Aufgabe 2.2

Diese Stufe wird freigeschaltet, sobald Sie die Stufe davor abgeschlossen haben.

Herr Sommer kauft bei einem Möbelhändler einen Esstisch auf Raten. Er glaubt, nur die Zinsen zahlen zu müssen. Der unterschriebene Vertrag sieht aber eine Tilgung der Kaufsumme in Raten vor.

Welche Einordnung passt zu Herrn Sommers Irrtum?

Stufe 4 von 4: Aufgabe 2.3

Diese Stufe wird freigeschaltet, sobald Sie die Stufe davor abgeschlossen haben.

Frau Adler kauft bei der Schreinerei Wilde einen Esstisch für 1.800 EUR. Sie hält die Tischplatte für massive Eiche. Beim Kauf wird darüber nicht gesprochen. Bei der Lieferung zeigt sich, dass die Platte nur aus einem Eichenfurnier auf einer Spanplatte besteht.

Welche rechtliche Einordnung passt?
